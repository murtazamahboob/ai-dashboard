    How this dashboard works

    1. Synthetic data, real signal. 2,000 customers are generated in Python from a known churn rule (tenure, charges, contract, support calls, usage, age, services) — no real customer data.
    2. Model trained from scratch. An 8→16→8→1 MLP in pure NumPy (Adam, 60 epochs) reaches the accuracy shown above. Its weights are exported to web/data/weights.json.
    3. Live inference in the browser. web/js/model.js runs the exact same forward pass in JavaScript — the Python and JS predictions agree to 1e-6, verified by the test suite.
    4. Charts drawn from scratch. Every chart is hand-drawn on <canvas> — no chart library, no CDN, no network requests at all.

    Open web/index.html directly in a browser, or serve the web/ folder with any static server. Dark mode is the default; the toggle is remembered.
